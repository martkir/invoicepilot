Source connection flow

Connect, disconnect, and what happens when credentials expire — as eight screens. Each frame is a real page using the app’s own tokens.css and dashboard.css, so these cannot drift from the product.

Two simplifications drive this flow. Disconnect acts on a single click, with no confirmation step. And expired credentials are not a separate state — a lapsed account is presented exactly as a disconnected one (screen 4), so there is no reconnect path and no wrong-account case to handle. You simply add the source again.
